# 1_History_JS

    JavaScript is a programming language used to make web pages interactive and dynamic.
    It adds functionality such as button clicks,form validation,animations,and content updates to websites.

    Example:-
    JavaScript

    console.log("Hello World");

# 2_Starter_JS

    Starter JavaScript refers to the basic concepts of JavaScript used to begin web development.It includes variables,data types,operators,functions,conditions,and loops,which help create interactive and dynamic web pages.

# 3_Variable_JS

    Variables are used to store data values in JavaScript.They allow programmers to save and reuse information such as numbers,text and other data types.Variables can be declared using let,const,or var.

    Example:-
    JavaScript

    let name="Chinmay";

# 4_Variables_keyword

    Variable keywords in JavaScript are used to declare variables.The three main keywords are var,let, and const.

    var - Older way to declare variables.
    let - Used for variables whose values can change.
    const - Used for variables whose values cannot be reassigned.

    Example:-
    JavaScript

    let age = 18;
    const country = "India";

# 5_String_Indexing_JS

    String Indexing in JavaScript is used to access individual characters of a string using their position(index).Indexing starts from 0,where the first character is at index 0.

    Example:-
    JavaScript

    let name="Chinmay";
    console.log(name[0]); // C

    Here,name[0] accesses the first character of the string.

# 6_String_methods_JS

    String methods are built-in JavaScript functions used to perform operations on strings,such as changing case,finding text,or extracting characters.

    Common methods:-
    1.toUpperCase() - Converts text to uppercase.
    2.toLowerCase() - Converts text to lowercase.
    3.trim() - Removes extra spaces.
    4.slice() - Extracts part of a string.

    Example:-
    JavaScript

    let name = "chinmay";
    console.log(name.toUpperCase()); //CHINMAY

# 7_Truthy_Falsy_JS

    In JavaScript,Truthy values are treated as true and Falsy values are treated as false when evaluated in a condition.

    Falsy values:false,0,""(empty string),null,undefined,NaN

    Truthy values:All other values are generally considered truthy.

    Example:-
    JavaScript

    let name = "Chinmay";

    if(name){
        console.log("Truthy value");
    }

    Since "Chinmay" is not empty,it is a truthy value.

# 8_Operators_JS

    Operators are symbols used to perform operations on variables and values in JavaScript,such as addition,subtraction,comparison,and logical operations.

    Example of Operators:-
    1.Arithmetic: +,-,*,/
    2.Comparison: ==,===,>,<
    3.Logical: &&,||,!

    Example:-
    JavaScript 

    let a=10;
    let b=5;

    console.log(a+b); //15

    Here,the + operator adds two numbers.

# 9_Loops_JS

    Loops in JavaScript are used to execute a block of code repeatedly until a specified condition is met.They help reduce code repetition and improve efficiency

    Common Loops: for,while,and do..while

    Example:-
    JavaScript

    for(let i=1;i<=5;i++){
        console.log(i);
    }

    This loop prints numbers from 1 to 5.
